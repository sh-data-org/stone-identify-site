Website privacy

This website is operated by Yoav Tzori and hosted on GitHub Pages.

Website visits

This static website does not currently use analytics cookies or collect page-view and download-click events. GitHub processes network information to serve and secure the site, including visitors’ IP addresses. See GitHub’s privacy statement.

External services

Download buttons open Apple’s App Store. Fonts are loaded from Google Fonts. These services receive ordinary network requests when used. The app has its own privacy policy.

No website accounts or uploads

This public site has no sign-in, photo scanner or upload form. App identification happens in the iPhone app.

Contact

For support or privacy requests, use the support information on the official app listing.
